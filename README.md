## How it is organised

One folder per question, inside chapter folders that group the questions by technique (`A1`…`A5` nested data, `C1`…`C11` web scraping, `G1`/`G2` one-offs, `X` the English-language sites). Each question folder holds:

- `question.md` — the question as asked, with its comments; the asker is named and linked, the licence is stated.
- `my-answer.md` — my answer, with its comments (`my-answer-2.md` where I answered twice).
- `other-answer-<id>.md` — every other answer on the question, kept as context; each names its author.
- `my-answer.py` / `.js` / … — the code blocks from my answer, verbatim, where the answer had code. Anything added later to make a folder runnable (requirements, sample input, a run note) is dated when it is added.

Each chapter folder has a README listing its questions; the index below is generated by `tools/build_index.py`.

## Dates and authorship

Git lets a commit carry any date and any author, which is what makes a migration honest or dishonest. Here, three kinds of commit hold the imported posts, and each says what it is:

- **My answers** (`my-answer.md`): author and committer are me, author date and committer date are both the moment I posted the answer, taken from the Stack Exchange API. These are the commits that count as my activity.
- **Questions** (`question.md`) and **other people's answers** (`other-answer-*.md`): the git author is the person who wrote the post, with a placeholder address in the reserved `.invalid` domain carrying their Stack Exchange user id (the real address is not public, and the placeholder can never deliver mail), and the author date is the moment they posted it; I am the committer, with the committer date set to the real import time. `git log --format=fuller` shows both dates on each of these commits, and GitHub lists them as authored by the poster and committed by fwSara95h, which is exactly what happened: their text, put into this repository by me in October 2026. None of them counts as my activity.
- **Everything else** — the extracted code files, the indexes, this README, and all later work — is committed by me when it was actually done.

Every commit message states the source URL, the posting date, the last revision date, the retrieval date and a sha256 of the text, so the history can be checked against Stack Overflow line by line. `Co-authored-by` trailers name anyone who later edited a post (an asker who edited my answer, an editor who tidied a question) and Claude, which generated the files and the import; the trailers are attribution, not a claim that those people worked in this repository.
