# My answer — 2023-01-02

Posted by me ([Driftr95](https://stackoverflow.com/users/6146136)) on Stack Overflow, <https://stackoverflow.com/a/74988002>, 2023-01-02; score 3. Text as retrieved 2026-10-12.

bs4 only parses HTML, not JavaScript (nor CSS); as some of the comments have mentioned, a common approach is to split `text` at `=` and use `json.loads` to parse `window.appCache`, but in this case, that will [still raise the `JSONDecodeError` error](https://i.sstatic.net/anTt6.png) because `window.appCache` contains [js functions](https://i.sstatic.net/VMTxO.png) and js primitive values ([like `undefined`](https://i.sstatic.net/kSqai.png)).

---

I have a function [`findObj_inJS`](https://pastebin.com/UVcLniSG) which uses [`slimit`](https://slimit.readthedocs.io/en/latest/) to parse a string containing JavaScript code and extract an object/variable from it. For example, `findObj_inJS(text, '"reviews"')` will return 

```python
{'name': 'Native_infosite_reviews_fluid_en-US', 'id': 'div-AdSlot-native-infosite-reviews', 'fluid': True}
```
