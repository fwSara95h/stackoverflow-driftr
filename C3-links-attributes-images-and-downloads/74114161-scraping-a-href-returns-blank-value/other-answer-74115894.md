# Answer by [Barry the Platipus](https://stackoverflow.com/users/19475185) — 2022-10-18

Posted on Stack Overflow, <https://stackoverflow.com/a/74115894>, 2022-10-18. Licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); reproduced in full as context for my answer — the text is the author's. Retrieved 2026-10-12.

Information in that page is being hydrated via XHR calls, by javascript. 
If you want to reach that information with Requests, you need to scrape the actual API endpoints. Here is one way to do it:

    import requests
    import pandas as pd
    
    pd.set_option('display.max_columns', None)
    pd.set_option('display.max_colwidth', None)
    
    r = requests.get('https://api.smws.com/api/v1/bottles?store_id=uk&parent_id=61&page=1&sortBy=pricedesc&minPrice=0&maxPrice=0&perPage=128')
    df = pd.json_normalize(r.json()['items'])
    print(df)
