If you just want to view the cookies being saved by your mobile's chrome, you can just use  [remote debugging][1],  which allows you to inspect the pages open on your phone, but the dev tools windows themselves have to be viewed on PC.

If you're not interested in remote, I've heard good things about [Eruda][2], which makes it possible to access dev tools on you mobile device. 


  [1]: https://developer.chrome.com/docs/devtools/remote-debugging/
  [2]: https://dev.to/asaoluelijah/how-to-access-dev-tool-on-mobile-browsers-14nd
